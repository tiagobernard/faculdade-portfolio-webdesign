# AULA PRÁTICA - WEB DESIGN
## Aluno: Tiago Bernardes

## Introdução
O presente projeto foi desenvolvido como parte das atividades práticas da disciplina de Web Design, com o objetivo de aplicar os conhecimentos adquiridos sobre estruturação de páginas web utilizando HTML e estilização com CSS. A atividade visa integrar elementos gráficos à interface, promovendo uma apresentação visual coesa e funcional.

## Justificativa
A construção de interfaces visuais é uma habilidade essencial para profissionais da área de desenvolvimento web. Compreender a relação entre estrutura, conteúdo e design é fundamental para oferecer experiências de navegação intuitivas. Esta prática proporciona a oportunidade de aplicar esses conhecimentos em um projeto prático, consolidando a teoria estudada.

## Conclusão
A atividade possibilitou a criação de uma página web utilizando HTML e CSS, integrando elementos gráficos desenvolvidos especificamente para o projeto. Com isso, foi possível compreender a importância do design responsivo, da organização visual e da aplicação correta de estilos para melhorar a usabilidade e a estética de uma interface web.
